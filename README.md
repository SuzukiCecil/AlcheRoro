# AlcheRoro（アルケロロ）

要件定義書（`要件定義書.md`）に基づく、プレイヤー vs CPU の2人対戦Webボードゲーム。

## 起動

```bash
npm install
npm run dev      # 開発サーバー
npm test         # ルール/AIのユニットテスト
npm run sim      # 戦略別CPU同士の総当たりシミュレーション（オプションは scripts/simulate.ts 冒頭）
npm run build    # dist/ に静的ビルド（Vercel / Cloudflare Pages にそのまま配置可）
```

## 構成

| パス | 役割 |
| --- | --- |
| `src/game/types.ts` | 定数・型定義 |
| `src/game/cards.ts` | 調合カード24枚（1点10枚・2点8枚・3点6枚、コスト2/3/5） |
| `src/game/engine.ts` | 純粋関数のゲームロジック（タイル取得・3:1変換・調合・終了判定） |
| `src/game/ai.ts` | ルールベースCPU（評価関数＋差し替え可能な戦略 `STRATEGIES`） |
| `src/game/search.ts` | 先読みCPU（自分と相手の手番を交互に読むアルファベータ探索。山札の中身は見ない） |
| `src/game/cpu.ts` | CPUの強さ（やさしい／ふつう／つよい）と、強さごとの取得・調合の判断 |
| `src/sim/simulate.ts`, `scripts/simulate.ts` | バランス検証用シミュレーター（結果：`docs/balance-*.md`） |
| `src/game/store.ts` | Zustandストア・CPU手番の進行（0.6〜1.0秒ウェイト） |
| `src/components/*` | ボード・カード・所持素材・モーダル |

## 素材

要件定義書の5色（内部IDは色名のまま）に、錬金素材のモチーフを割り当てています（`src/game/types.ts` の `MATERIAL`）。

| 色 | 素材 | アイコン |
| --- | --- | --- |
| 赤 | 火トカゲの鱗 | 鱗片 |
| 青 | 人魚の涙 | しずく |
| 緑 | マンドラゴラ | 葉と根 |
| 黄 | 硫黄 | 結晶 |
| 紫 | 夜光キノコ | 斑点のあるキノコ |

## 調合カード

カードの共通レイアウト・枠の意匠・イラストの入稿ルールは [`docs/card-spec.md`](docs/card-spec.md) を参照。
イラストは `public/cards/<ID>.jpg` に置くと反映され、`/?gallery` で全24枚を確認できる。

## 要件定義書から補完した仕様

- **初期配置**：36マスのうち1マスを「予備」として空け、そこに矢印を置く。残り35マスに5種×7枚を配置。初期の向きはランダム。
- **調合**：1手番に複数枚調合可。「調合する」でカードを選んで実行、「手番終了」で交代。
- **3:1変換**：自分の手番中なら、所持欄の3個以上ある素材をタップしていつでも手動で変換できる（同じ素材3個 → 好きな素材1個）。調合には素材そのものが必要で、変換すれば作れるカードには「変換で達成可能」と内訳を表示する。調合時の自動変換は機能として残してあり、`src/game/store.ts` の `AUTO_CONVERT` を true にすると有効になる（切り替えスイッチは外した）。CPUは常に自動変換。
- **山札切れ**：補充できない枠は空欄のまま。
- **カード構成（要件定義書から変更）**：要件の「各ランク均等・コスト2〜4」では3点カードを貯めて狙う戦略が強すぎたため、1点10枚・2点8枚・3点6枚、3点カードのコストを5個に変更（`docs/balance-current.md`）。
- **手番の選択**：開始時に先手・後手・ランダムを選ぶ。選ぶまで場のカードは伏せておき、盤面は選択画面で見えていたものをそのまま使う。
- **CPUの強さ**：開始画面で やさしい／ふつう／つよい を選ぶ（次回のために保存）。やさしい＝小刻み戦略＋半分の確率でランダムなマス、ふつう＝2点狙い（旧つよい）、つよい＝先読み（1手番0.4秒を目安に、最大12手先＝自分と相手6手番ずつまで読む）。勝率は `docs/balance-cpu.md`。
- **一手戻る（デバッグ用）**：開発サーバー、または URL に `?debug` を付けたときだけ、ヘッダーに戻るボタンを出す。自分の操作（取得・調合・変換・手番終了）を1つずつ取り消せ、手番終了を取り消すとその後のCPUの手番も取り消される。ゲーム終了画面にも同じボタンを出す。
- **後手ボーナス（追加ルール）**：先手有利（勝率約60%）の補正として、後手はランダムな素材を持って始める。個数は開始画面で0〜2個から選べる（既定は `SECOND_PLAYER_BONUS` の1個、選択は保存）。開始時に画面中央で素材を見せ、OK を押すと所持欄へ飛ばす（それまでゲームは進まない）。
- **リプレイ**：結果モーダルの「もう一度遊ぶ」で新規ゲーム。
