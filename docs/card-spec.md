# 調合カード 共通仕様

全24枚の調合カードは、この仕様の**共通レイアウト**で表示する。実装は `src/components/RecipeCardFace.tsx`、全カードの確認は `/?gallery` で行える。

## 1. 掲載情報

| 情報 | 内容 |
| --- | --- |
| カード名 | 最大6文字（全角） |
| 得点 | 1〜3点 |
| イラスト | カード1枚につき1点 |
| 必要素材 | 2・3・5個（1点・2点・3点） |

ゲーム中の状態（選択中・達成可能・3:1変換の内訳）は**カードの外側**に表示し、カード面には載せない。

## 2. レイアウト

縦横比 **3:4** の縦長カード。寸法はすべて**カード幅 W に対する比率**で定め、表示サイズが変わっても配置比率は変えない。

```
┌───────────────────────┐ ← 枠（幅 4.5%W、点数で意匠が変わる）
│ ┌───────────────────┐ │
│ │ カード名       (3)│ │ ← 名前帯（高さ 20%W）
│ ├───────────────────┤ │
│ │                   │ │
│ │     イラスト      │ │ ← イラスト領域（約 91%W × 82%W、ほぼ正方形）
│ │                   │ │
│ ├───────────────────┤ │
│ │   ●  ●  ●  ●      │ │ ← 素材帯（高さ 22%W）
│ └───────────────────┘ │
└───────────────────────┘
```

| 領域 | 位置・寸法 | 内容 |
| --- | --- | --- |
| 枠 | 外周 4.5%W、角丸 6%W | 点数ごとの意匠（§3） |
| 名前帯 | 上端、高さ 20%W | カード名を左寄せで表示（文字 10.5%W・極太）。右端に得点メダル（直径 16%W） |
| イラスト領域 | 名前帯と素材帯の間 | 画像を中央でトリミングして全面に表示。上に文字やアイコンは重ねない |
| 素材帯 | 下端、高さ 22%W | 必要素材を必要数ぶん、中央に1列で並べる（白丸 15%W、アイコン 10.5%W。最大5個） |

### 素材の並び順

全カード共通で **火トカゲの鱗 → 人魚の涙 → マンドラゴラ → 硫黄 → 夜光キノコ**。必要数ぶん同じアイコンを並べる（例：鱗2個ならアイコン2個）。

### 最低表示サイズ

スマホでの最小カード幅は約 96px。このとき、カード名は約 10px、素材アイコンは約 10px で表示される。これより小さく表示しない。

## 3. 枠（点数ごとの意匠）

| 点数 | 枠 | 名前帯・素材帯 | 装飾 |
| --- | --- | --- | --- |
| 1点 | 銅（ブロンズのグラデーション） | 薄い銅色 | 四隅に鋲 |
| 2点 | 銀（シルバーのグラデーション） | 薄い銀色 | 四隅に鋲 ＋ 縁に沿った線飾り |
| 3点 | 金（ゴールドのグラデーション） | 薄い金色 | 四隅に赤い宝石 ＋ 線飾り ＋ 上下中央に菱形飾り |

得点メダルも枠と同じ色系統にし、数字は白で表示する。点数は数字・枠の色・装飾の3つで区別できるようにする。

## 4. イラスト

### ファイル

- 置き場所：`public/cards/<ID>.jpg`（ID は §5 の一覧を参照。Gemini が出力する JPEG をそのまま置く）
- サイズ：**1024×1024px の正方形**（表示時は上下を少しトリミングする）
- 未配置のカードには、素材の色を使った仮の画像（フラスコのアイコン）が自動で表示される

### 描き方のルール

- 描くもの（調合品）は**画像の中央 80% に収める**。端はトリミングされる可能性がある
- **文字・数字・枠線・カードの縁は描かない**（ゲーム側で付けるため）
- 背景はシンプルにし、調合品を主役にする
- 全カードで画風・光の向き・背景の雰囲気をそろえる
- 必要素材の色味（下表）をイラストに取り入れる

| 素材 | 色 |
| --- | --- |
| 火トカゲの鱗 | 赤 |
| 人魚の涙 | 青 |
| マンドラゴラ | 緑 |
| 硫黄 | 黄 |
| 夜光キノコ | 紫 |

### 生成プロンプトのひな形

2点・3点カードの演出とカード別プロンプトは `docs/card-prompts.md` を参照。

```
ファンタジー世界の錬金術で作られた「{カード名}」のイラスト。
{調合品の見た目の説明}。
素材として{素材名の一覧}が使われており、{色の一覧}の色味を取り入れる。
柔らかい水彩風、中央に調合品を1つ大きく配置、シンプルで明るい背景、
正方形 1:1、文字・枠線・ロゴは入れない。
```
