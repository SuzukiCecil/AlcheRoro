# 2点・3点カードのイラスト演出と生成プロンプト

## 演出の方針

点数が上がるほど「静 → 動 → 伝説」と格が上がるように描き分ける。小さく表示しても（96px）違いがわかるよう、変えるのは**舞台・光の強さ・調合品の状態**の3つに絞る。

| | 1点（銅） | 2点（銀） | 3点（金） |
| --- | --- | --- | --- |
| テーマ | 完成品が置いてある | 魔法が発動している瞬間 | 伝説級の秘宝 |
| 舞台 | 工房の作業台 | 同じ工房（背景は暗めに沈める） | 工房を離れ、闇に浮かぶ金色の魔法陣 |
| 調合品 | 台の上に静かに置かれる | 台から少し浮き上がる | 宙に浮かび、大きく描く |
| 光 | 調合品がほのかに光る | 素材の色の魔力が渦を巻いて器を取り巻く | 光が放射状に伸び、金色の粒子が舞う |
| 演出 | なし | カードごとの属性の演出（炎・氷・雷など）を1つ | 背後に象徴的なモチーフ（不死鳥の翼、竜の眼など） |

- 2点は1点と同じ工房の背景にして、「同じ世界の格上の品」に見せる
- 3点だけは背景を変え、ひと目で別格とわかるようにする。金の光は金枠になじむ
- 主な演出は画像の中央80%に収める。カードでは上下が少し切れるため、縦長の光の柱などは主役にしない

## 生成のコツ（Gemini）

- 1点の画像を1枚（例：`spark-powder.jpg`）添付し、「添付画像と同じ画風」と指示すると、画風と工房がそろう
- 同じ点数のカードは同じチャットで続けて生成すると、ばらつきが減る
- 魔法陣は文字のような模様になりやすいので、「幾何学模様のみ・文字なし」と明記する
- 「〜しない」より「〜にする」と書いたほうが守られやすい。禁止事項は最後に1行でまとめる

## 2点カード（銀枠）

### 共通プロンプト

```
添付画像と同じ水彩の画風・同じ錬金術の工房（本棚、吊るした薬草、木の作業台）で、「{カード名}」を描いてください。
添付画像より格上の調合品として、魔法が発動している瞬間を表現します。

- 調合品：{見た目}
- 演出：{演出}
- 調合品は作業台から少し浮き上がり、{色}の魔力がらせん状に器を取り巻く
- 工房の背景は暗めに沈め、調合品の光で周囲が照らされる
- 調合品と演出は画像の中央80%に収める
- 正方形1:1。文字・数字・枠線・ロゴは描かない
```

## 3点カード（金枠）

### 共通プロンプト

```
添付画像と同じ水彩の画風で、「{カード名}」を描いてください。
最も格の高い、伝説級の調合品として表現します。

- 舞台：工房ではなく、深い闇の中。背後に金色に輝く円形の魔法陣（幾何学模様のみ・文字なし）が浮かび、そこから光の筋が放射状に伸びる
- 調合品：{見た目}。宙に浮かび、画面の主役として大きく描く
- 演出：{演出}
- 金色の光の粒子が舞い、暗い背景に金と{色}が映える高いコントラストにする
- 調合品と演出は画像の中央80%に収める
- 正方形1:1。文字・数字・枠線・ロゴは描かない
```

## 記入例（炎の霊薬）

```
添付画像と同じ水彩の画風・同じ錬金術の工房（本棚、吊るした薬草、木の作業台）で、「炎の霊薬」を描いてください。
添付画像より格上の調合品として、魔法が発動している瞬間を表現します。

- 調合品：赤く燃える液体が入った丸いフラスコ。液体の中で炎が揺らめく
- 演出：瓶の口から炎の渦が立ち上り、火の粉が舞う。作業台に赤い鱗と黄色い硫黄のかけら
- 調合品は作業台から少し浮き上がり、赤と黄の魔力がらせん状に器を取り巻く
- 工房の背景は暗めに沈め、調合品の光で周囲が照らされる
- 調合品と演出は画像の中央80%に収める
- 正方形1:1。文字・数字・枠線・ロゴは描かない
```
